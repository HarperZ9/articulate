# Dialogue test fixtures

`pygmalion-act2.txt` is an excerpt from Act II of *Pygmalion* by Bernard Shaw,
first published in 1913 and in the public domain in the United States. It was
read from Project Gutenberg eBook 3825. The Project Gutenberg header, footer
and trademark are not included. The tests use it as dialogue written by a
person, which the dialogue profile should mostly leave alone.
